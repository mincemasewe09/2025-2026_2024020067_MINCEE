Program Studi

Fakultas Ilmu Komputer

S1 Teknik Informatika

Program Studi Teknik Informatika mempelajari pengembangan perangkat lunak, kecerdasan buatan, jaringan komputer, keamanan sistem, basis data, serta teknologi informasi yang mendukung era digital.

S1 Sistem Informasi

Program Studi Sistem Informasi mempelajari analisis sistem, manajemen teknologi informasi, pengembangan aplikasi bisnis, serta tata kelola sistem informasi.

S1 Teknologi Informasi

Program Studi Teknologi Informasi berfokus pada pengelolaan infrastruktur TI, cloud computing, keamanan jaringan, serta transformasi digital.

Program Studi Lainnya

Kewirausahaan
